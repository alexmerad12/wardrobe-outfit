## Gotchas
- Several sessions work in this repo's checkouts at once. Before starting a local server check the port is free, wait for your own process's "Ready" line, and stop it by the process id you started (`CLAUDE.md`, Commands). Every script that makes real AI calls should refuse a host other than localhost. Before a run on the e2e account, tell the other Linette sessions and wait for their "all clear": overlapping runs once wiped its wardrobe.
- Working copies are CRLF (git stores LF): a multi-line Edit anchor misses on them. Anchor on single lines, or delete the unchanged file and `git -c core.autocrlf=false checkout -- <file>` for an LF copy (`CLAUDE.md`, Deploy).
- `?debug=rules` and the cap bypass need the email in `CAP_BYPASS_EMAILS`: true on a local server started with it, not on production, where the e2e account's caps apply (suggest 3 a day).
- Env vars that exist locally but not on Vercel fail silently in production; sensitive Vercel variables are write-only (`CRON_SECRET`: test with `vercel crons run /api/cron/keepalive`).
- The e2e account is grandfathered (created before the paywall cutoff): to test the paywall, serve the local build's `paywall.html` (Playwright `route.fulfill`) or use an account the paywall stops.
- Gemini free tier: 20 requests per model per day, reset at midnight Pacific. If AI Studio shows "Account inactive", reopen the Cloud billing account.
- Supabase: new `public` tables need explicit GRANTs to anon/authenticated in their migration. Supabase checks a redirect against its allow list after Google, not at `/authorize`: the admin `generateLink` call runs the same check at once and shows the address it kept.
- Never trust `URL.host` on an `app.linette://` link: WebViews before Chromium 130 parse no host there (`known-root-causes.md`).
- A local `next start` keeps Next's fetch cache in `.next/cache/fetch-cache` between runs: on 2026-11-19 a local server served Montreal weather from days before (`known-root-causes.md`, weather entry).
- After a context compaction, re-read files from disk before "fixing" what looks like a revert.
